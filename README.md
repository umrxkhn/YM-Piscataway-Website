# YM Piscataway Website

Official website for the local YM Piscataway youth group chapter, featuring upcoming events, programs, activities, community updates, and opportunities for youth to stay connected and involved.

## Live Website

ympiscataway.com

## About the Project

This website was created to provide a central online platform for the YM Piscataway chapter. It allows visitors to learn more about the chapter, view upcoming events and activities, stay updated with announcements, and easily access important information.

## Features

- Upcoming events and activities
- Chapter information
- Community updates
- Mobile-friendly design
- Easy navigation
- Modern and responsive interface

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase
- Lovable
